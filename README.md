# RAVEN'sノート

个人日语复习网页。把纸质教材《从日本中小学课文学日语》里的词汇、语法和例句整理成数字知识库，利用碎片时间复习。

- 在线访问：<https://zyszcsz-janejoy.github.io/ravens-note/>
- 手机优先、支持添加到主屏幕、可离线使用
- 不需要注册登录，学习数据只保存在你自己的浏览器里
- 访问需要密码，密码由项目所有者单独保存，不写在仓库里

---

## 一、功能一览

| 页面 | 能做什么 |
| --- | --- |
| 首页 | 查看今日待复习的词汇、语法、输出练习；按 3 / 5 / 10 / 15 分钟或不限时间推荐任务；查看最近学习的课文 |
| 复习 | 词汇卡（假名、意思、例句可分别显示）、语法选择题、中文翻日语、自由造句；支持中途退出并下次继续 |
| 录入 | 手动添加、修改、删除词汇和语法；词汇 9 个字段，语法 10 个字段；保存后自动保留来源课文 |
| 知识库 | 词汇库 / 语法库 / 课文库三栏；搜索与筛选；管理课文与词汇、语法的关联；查看语法四个方面的掌握度 |
| 我的 | 累计词汇与语法、学习记录、错题本、导出与导入 JSON、锁定设备、清空数据 |

复习相关的规则：

- 四档自评：完全忘记 / 模糊 / 基本掌握 / 熟练
- 间隔：忘记当天稍后再看；模糊次日；基本掌握 3 天后；熟练 7 天起，连续熟练延长到 14～30 天
- 语法的「意思理解、接续、中译日、自由造句」分别记录，选择题答对只算基本掌握，不代表语法已经熟练
- 答错时可以记录错误类型：忘记意思、忘记接续、不会主动调用、相似语法混淆、句子表达错误

当前为第一阶段，**没有**接入 AI 拍照、AI 出题、AI 批改、语音识别、发音评分、账号、云同步、社交和排行榜。

## 二、在手机上使用

### 1. 打开网站

用手机浏览器访问：

<https://zyszcsz-janejoy.github.io/ravens-note/>

首次打开会显示「解锁笔记本」，输入访问密码后进入。勾选「7 天内在这台设备上免输入」，之后 7 天内不需要重复输入。

### 2. 添加到主屏幕

- iPhone：用 **Safari** 打开 → 底部「分享」→「添加到主屏幕」
- Android：用 **Chrome** 打开 → 右上角菜单 →「添加到主屏幕」或「安装应用」

添加后从桌面图标打开，就是全屏的应用体验；打开过一次后，断网也能继续复习。

### 3. 重新上锁

进入「我的」页面 →「其他」→「锁定本设备」→「立即锁定」。当前设备会清除免密状态，下次打开需要重新输入密码。

### 4. 记录第一条内容

1. 打开「知识库」→「课文」→ 新建课文（例如「第 1 课」）
2. 打开「录入」→ 选择「词汇」，填写单词、假名、中文意思等，来源课文选择刚建的课文
3. 切换到「语法」，填写语法名称、接续、中文意思、例句和例句翻译
4. 回到首页，就会出现今日待复习任务

> 中译日和选择题需要语法里填写了**例句和例句翻译**才会生成；只填语法名称不会生成这两类练习。

## 三、数据保存在哪里

- 所有数据保存在浏览器的 **IndexedDB** 中，不上传任何服务器，换设备不会自动同步。
- 刷新页面、关闭浏览器都不会丢失。
- **清除浏览器数据、卸载浏览器、使用「无痕模式」会导致数据丢失。**
- 更换手机、更换浏览器或长期使用前，请先备份。

### 导出备份

「我的」→「数据管理」→「导出 JSON」，会下载一个包含全部词汇、语法、课文、例句、复习记录和错题的 JSON 文件。也可以点「复制数据」把 JSON 复制到剪贴板。

### 导入恢复

「我的」→「数据管理」→「导入 JSON 备份」→ 选择文件 → 确认导入。

- 导入采用**合并**方式，不会覆盖现有内容
- 相同词汇（单词 + 假名）、相同语法（名称 + 接续）、相同课文标题会自动跳过，不会重复
- 导入前会先显示文件里的数据数量
- 导入前建议先导出一份当前数据作为备份

### 清空数据

「我的」→「其他」→「清空数据」→ 输入「删除」两个字 →「永久清空」。此操作不可恢复。

## 四、本地运行（Windows）

仓库自带便携版启动脚本，但需要先有构建产物。

1. 安装依赖并构建（只需做一次，或在代码更新后重新执行）：

   ```bash
   npm install
   npm run build
   ```

2. 双击项目根目录的 `启动本地预览.bat`
3. 电脑访问 <http://127.0.0.1:4173>
4. 手机与电脑连同一个 Wi-Fi，访问窗口里显示的 IPv4 地址加 `:4173`

> 局域网 HTTP 只能浏览，Service Worker 和「添加到主屏幕」的离线功能需要 HTTPS，因此正式使用请用线上地址。

开发模式（修改代码时使用）：

```bash
npm run dev
```

数据层自测：

```bash
npm run test:data
```

需要 Node.js 20 或更高版本。

## 五、部署说明

项目使用 GitHub Pages 自动部署：

- 工作流文件：`.github/workflows/deploy.yml`
- 推送到 `main` 分支后，自动执行 `npm ci`、`npm run build`，并把 `dist` 发布到 GitHub Pages
- 也可以在仓库的 Actions 页面手动触发 `Deploy to GitHub Pages`

首次在新仓库启用时，需要在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。

> Pages 免费版要求仓库为公开仓库。当前网站只包含程序代码，学习数据并不在仓库里。

## 六、项目结构

```text
ravens-note/
├─ src/
│  ├─ pages/             五个主页面与错题页
│  ├─ components/        通用 UI、底部导航、录入表单、复习卡片、锁屏
│  ├─ db/                IndexedDB 封装与数据仓库
│  ├─ lib/               间隔重复、任务编排、选择题、密码校验、工具函数
│  ├─ store/             全局数据加载与提示
│  └─ types.ts           数据类型定义
├─ public/icons/         PWA 图标
├─ scripts/              图标生成与数据层测试
├─ .github/workflows/    GitHub Pages 自动部署
├─ 启动本地预览.bat      Windows 本地预览
└─ vite.config.ts        Vite 与 PWA 配置
```

技术栈：React 18 + TypeScript + Vite + Tailwind CSS + 原生 IndexedDB + vite-plugin-pwa。

## 七、修改访问密码

密码只以 SHA-256 哈希形式保存在 `src/lib/auth.ts` 的 `PASSWORD_HASH` 常量中，仓库里没有明文密码。

1. 计算新密码的哈希（PowerShell）：

   ```powershell
   $pw = '你的新密码'
   $sha = [Security.Cryptography.SHA256]::Create()
   -join ($sha.ComputeHash([Text.Encoding]::UTF8.GetBytes($pw)) | ForEach-Object { $_.ToString('x2') })
   ```

2. 把输出的十六进制字符串替换到 `src/lib/auth.ts` 的 `PASSWORD_HASH`
3. 重新构建并部署

注意：这是前端访问门槛，能阻止别人随手打开网址，但代码是公开的，不能当作真正的加密保护。学习数据只存在各自设备的浏览器中。忘记密码时同样通过修改 `PASSWORD_HASH` 重置。

## 八、常见问题

**刷新后数据还在吗？**
在。数据实时写入 IndexedDB，刷新、关闭页面都不会丢。

**换了手机，数据会同步吗？**
不会。请先在旧设备「导出 JSON」，再到新设备「导入 JSON 备份」。

**为什么「中译日」和「选择题」没有内容？**
需要给语法填写例句和例句翻译，系统才能生成这两类练习。

**为什么添加到主屏幕后还是普通网页？**
必须使用 HTTPS 地址；本地 `192.168.x.x` 的 HTTP 地址不支持完整的 PWA 功能。

**忘记密码怎么办？**
按第七节修改 `PASSWORD_HASH` 后重新部署。忘记密码不影响已有数据。

**可以同时用电脑和手机吗？**
可以，但两边数据独立。要共用内容，用导出/导入 JSON 合并。

**数据安全吗？**
数据不上传服务器，只在本机浏览器中；网站有密码门，但公开仓库中的前端密码无法提供服务器级安全。请定期导出备份，并妥善保管设备。
